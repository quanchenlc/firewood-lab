# Asset attribution (CC0 / permissive only)

Downloaded textures are from [Poly Haven](https://polyhaven.com) under **CC0**.
The chopping stump mesh is from [Blendkit](https://www.blendkit.com) under **CC0**.
End-grain maps are procedural rings generated by `scripts/endgrain-canvas.mjs`.

## Wood material pack layout (ref roles — logic only)

Each species uses **three photo roles** matching screen.toys/firewood materials
(`outsidebark` / `insidegrain` / `top`) — **CC0 sources only; never their files**:

| Role (ref) | Local path | Purpose |
|------------|------------|---------|
| outsidebark | `bark/{species}/{diff,nor,rough}.jpg` | Cylindrical mantle wrap (`RepeatWrapping`) |
| insidegrain | `facegrain/{species}/insidegrain_{diff,nor}.jpg` | Cut-face bark-edge atlas (thin bark L/R + grain mid) |
| top | `endgrain/{species}.png` | Cap end-grain rings |

Per-species insidegrain atlases are built by `scripts/barkedge-atlas.py`
(species bark strips + shared kitchen_wood longitudinal grain, contrast-boosted,
no ×1.18 wash). Shared fallback: `facegrain/barkedge_{diff,nor}.jpg` (= toona pack).
